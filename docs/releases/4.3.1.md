# OMR Grader 4.3.1

상태: 배포됨. 빌드 번호 42, GitHub 릴리즈
[v4.3.1](https://github.com/kaicot/omr-grader/releases/tag/v4.3.1)(태그 커밋 `d83663c`).

인식 프로필 목록을 알아보기 쉽게 고친 버전입니다. 판독 엔진과 채점 규칙은 바꾸지 않았습니다.
**자료 형식 변경: 없음**(형식 1).

## 바뀐 점

- **인식 프로필 목록에 양식 내용을 보여 줍니다.** 스캔으로 자동 저장한 양식은 모두 이름이
  "자동 인식 양식"이라 100문항 양식과 60문항 양식을 구분할 수 없었습니다. 이제
  `객관식 60문항 · 학번 8자리 (자동, fbf823)`처럼 문항 수, 학번 자리 수, 파일 이름 끝의 구분 번호로
  보입니다. 직접 가져온 양식은 원래 이름 뒤에 문항 수를 붙입니다.
- **목록 아래 설명 줄**은 `양식: 객관식 60문항(1~20, 21~40, 41~60) · 학번 8자리 | 파일: … | 상태: 검증
  완료`처럼 문항 범위와 파일 이름을 보여 줍니다.
- 저장된 양식 파일은 바꾸지 않습니다. 보여 주는 방식만 바뀌므로 지금 있는 양식도 그대로 새 이름으로
  보입니다.

  다른 위치로 옮긴 폴더의 실행 시험도 통과했습니다.
