# OMR Grader 4.0.3

상태: 배포 후보(빌드 번호 28). 검증 결과는 아래에 적습니다.

[4.0.2](4.0.2.md)를 쓰면서 나온 요청을 반영한 버전입니다. 판독 엔진과 채점 규칙은
바꾸지 않았습니다. 포터블 경로, 배포 형식, receipt 형식 2와 검증 절차는 4.0.2와 같습니다.
아직 실제로 쓴 시험 기록이 없어, 예전 버전에서 만든 결과 파일 이름과 시트 이름은 더
지원하지 않습니다. 이 버전에서 다시 스캔해 쓰세요.

## 바뀐 점

- **인식이 끝난 뒤 안내.** 인식이 끝나면 "✓ OMR 인식 완료: 12장 중 12장 자동 판독(확인
  필요 n장)"과 "다음 단계: 정답/채점 화면에서 정답표를 불러와 채점하세요."를 보여 줍니다.
  맨 아래 파란 버튼은 '정답/채점으로 이동 →'으로 바뀌고, 'OMR 인식 실행'은 시험명이나 스캔을
  바꾸거나 초기화할 때까지 꺼 둡니다. 같은 스캔을 다시 실행해 시험이 두 번 만들어지는 일을
  막기 위해서입니다. 왼쪽 '정답/채점' 메뉴에는 "◀ 다음" 표시가 붙고, 그 화면으로 가면
  사라집니다. 아래쪽 "현재 세션"도 방금 만든 시험 이름으로 바뀝니다.
- **채점결과 Excel.**
  - 파일명: `261007_155703_채점결과_26_1졸업고사p1.xlsx`처럼 날짜_시각_종류_시험명입니다.
    채점 전 파일은 `…_응답결과_…`, 확정본은 `…_최종성적표_…`입니다. 날짜·시각은 시험을
    처음 만든 때라 재채점해도 이름이 바뀌지 않습니다.
  - 탭 순서: 채점결과 → 결과OX → 응답원본 → 정답표 → 색 설명
  - 채점결과: 순번 · 학번 · 이름 · 총점 · 석차 · Q1~Q100 · 비고. 순번은 이름 가나다순으로
    매겨 마지막 번호가 응시 인원입니다. 문항 칸에는 학생이 고른 답(예: 3, 1,3)이 있고,
    틀린 답·무응답·중복 표기는 분홍 바탕에 빨간 글씨, 확인 필요는 노랑입니다.
  - 결과OX: 같은 열 구성에 O·X·제외·검토로 표시합니다.
  - 응답원본: 읽은 답 그대로이며 '응답 엑셀로 시작'은 이 탭을 읽습니다.
  - 순번부터 석차까지는 옆으로 넘겨도 보이게 고정합니다.
- **시험 관리 대시보드.**
  - 채점일시가 세계 표준시로 나와 9시간 늦게 보이던 오류를 고쳐 한국 시간으로 보여
    줍니다. 연도 필터도 한국 시간 기준입니다.
  - '상태' 열: 채점 전 · 채점 완료 · 확정과 "확인 필요 n장"
  - 위쪽 요약: "시험 n개 · 채점 전 n개 · 확인 필요가 남은 시험 n개"
  - '새로고침' 버튼. 대시보드를 열 때마다 목록을 다시 읽습니다.
  - '채점하기': 고른 시험을 정답/채점 화면에 연결합니다. 스캔만 해 두고 나중에 채점할 때
    씁니다. 확정한 시험은 채점할 수 없습니다.
  - '결과 엑셀 열기'(행의 '엑셀' 버튼)와 '폴더 열기'
- **삭제·복구 실패를 확인 창으로 알림.** 시험 폴더 안의 Excel이 엑셀에 열려 있거나 탐색기
  창에서 그 폴더를 보고 있으면 Windows가 폴더를 옮기지 못해 삭제가 실패합니다. 4.0.2까지는
  창 맨 아래에 "[WinError 5]…"가 잠깐 나와 삭제가 된 줄 알기 쉬웠습니다. 이제 "시험 폴더가
  다른 프로그램(엑셀, 탐색기 창 등)에서 열려 있어 옮기지 못했습니다. 그 파일이나 폴더 창을
  닫고 다시 시도하세요."를 확인 창으로 보여 줍니다. 백신 검사처럼 잠깐 잡혔다 풀리는 경우를
  위해 약 3초 동안 다시 시도합니다. 상세 보기로 열려 있는 시험도 그렇다고 알려 줍니다.
- **환경 설정의 데이터 저장 경로.** 잘못된 안내 문구 대신 실제 `Data` 폴더 경로를 보여
  주고 '폴더 열기' 버튼을 두었습니다. 저장 위치는 바꿀 수 없으며, 다른 곳에 두려면
  프로그램을 끈 뒤 프로그램 폴더 전체를 옮깁니다.
