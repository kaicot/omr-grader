# OMR Grader 4.2.3

상태: 후보. 빌드 번호 38(후보).

시작을 빠르게 하고 배포본을 정리한 버전입니다. 프로그램 기능, 판독 엔진, 채점 규칙은 바꾸지 않았습니다.
**자료 형식 변경: 없음**(형식 1).

## 바뀐 점

- **시작이 약 1.3초 빨라졌습니다.** 프로그램을 켤 때 뜨는 로딩 화면에 Qt 기본 기능
  (`QSplashScreen`)을 쓰고 있었는데, 이 기능이 Windows에서 창을 띄울 때마다 약 1초씩 붙잡고
  있었습니다. 같은 모양의 가벼운 창으로 바꿔, 이 PC에서 메인 창이 뜨기까지 평균 3.97초 →
  2.63초, 로딩 화면이 보이기까지 1.5초 → 0.6초가 되었습니다(각 5회 측정). 퀴즈 리포터를 만들며
  찾은 문제입니다.
- **배포본에서 쓰지 않는 부품을 뺐습니다.** 배포 폴더 254 MB → 178 MB, ZIP 100 MB → 69 MB.
  - OpenCV에 딸려 오던 동영상용 FFmpeg(약 28 MB, LGPL). 이 프로그램은 스캔 이미지와 PDF만
    읽습니다.
  - 화면에 쓰지 않는 Qt 부품(약 48 MB): 소프트웨어 OpenGL, Qt 번역 파일, 화상 키보드와 그것이
    끌고 오던 Qt Quick · QML, Qt PDF(PDF는 pypdfium2가 읽음), Qt 네트워크와 TLS · 네트워크 정보 ·
    터치 입력 플러그인. 프로그램은 Qt의 Core · Gui · Widgets만 씁니다. 새 버전 확인은 파이썬의
    HTTPS 기능을 그대로 씁니다.
  - 배포 폴더의 모든 DLL을 검사해, 남은 부품이 필요로 하는 DLL이 하나도 빠지지 않았음을
    확인했습니다.
- **Qt 소스 안내.** 화면에 쓰는 Qt와 Qt for Python(PySide6)은 LGPL-3.0으로 씁니다. 배포 폴더의
  `_internal\THIRD_PARTY_NOTICES.txt`에 이 부품들이 따로 떨어진 라이브러리로 들어 있어 바꿔 끼울 수
  있다는 점과, 같은 버전의 소스를 받을 수 있는 공식 주소를 적었습니다.
- **저장소 정리.** 고정 버전 목록(`constraints/windows-py312.lock`)에 남아 있던 PyMuPDF와 예전
  pytest를 고치고, 빠져 있던 tzdata · attrs를 넣었습니다. 쓰지 않는 `packaging/startup_splash.svg`를
  지웠습니다.
- **테스트 도구 업데이트.** 개발용 테스트 도구 pytest를 알려진 취약점(PYSEC-2026-1845)이 고쳐진
  9.0.3으로 올렸습니다. pytest는 배포본에 들어가지 않습니다.
