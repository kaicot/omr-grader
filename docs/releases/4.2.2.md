# OMR Grader 4.2.2

상태: 배포됨. 빌드 번호 37, GitHub 릴리즈
[v4.2.2](https://github.com/kaicot/omr-grader/releases/tag/v4.2.2)(태그 커밋 `f4cc55b`).

PDF를 읽는 부품을 바꾸고 라이선스를 정한 버전입니다. 판독 엔진과 채점 규칙은 바꾸지 않았고,
실제 자료로 판독 결과가 4.2.1과 같음을 확인했습니다. **자료 형식 변경: 없음**(형식 1).

## 바뀐 점

- **PDF 엔진 교체.** 스캔 PDF를 이미지로 바꾸는 부품을 PyMuPDF에서 **pypdfium2**(Chrome의
  PDF 엔진 PDFium, BSD-3 · Apache-2.0)로 바꿨습니다. PyMuPDF는 AGPL-3.0 또는 유료 상업
  라이선스로만 쓸 수 있어, 프로그램에 함께 넣어 배포하면 프로그램 전체를 AGPL로 공개해야
  했습니다.
  - 열람 암호가 걸린 PDF와 깨진 PDF는 예전처럼 거부합니다. 쪽수 · 크기 제한도 그대로입니다.
  - 배포 폴더가 약 30 MB 작아졌습니다.
- **라이선스.** [PolyForm Noncommercial 1.0.0](../../LICENSE.md)을 붙였습니다. 소스는 공개하지만
  오픈소스(OSI) 라이선스는 아닙니다.
  - 개인 학습 · 연구 · 취미 등 비영리 목적은 누구나 무료로 쓰고 고치고 나눌 수 있습니다.
  - 학교 · 대학 · 공공 연구기관 · 정부기관 · 비영리 단체의 사용은 비용 출처와 관계없이
    허용됩니다.
  - 학원 · 업체의 영리 목적 사용은 제작자(kaic21@gmail.com)에게 문의해야 합니다.
  - 라이선스 원문은 배포 폴더의 `_internal\LICENSE.md`에도 들어 있고, 도움말 '프로그램
    정보'에 안내했습니다. 4.2.2 이전에 배포한 버전에도 같은 조건이 적용됩니다.
- **판독 기준 도구.** 실제 자료 판독 기준(G1)이 그동안 제품 코드가 아니라 PyMuPDF로 PDF를 직접
  렌더하고 있었습니다. 이제 제품의 PDF 경로를 거쳐, 배포되는 경로를 그대로 검증합니다.
- 테스트용 PDF는 의존성 없이 직접 써서 만듭니다. 저장소와 배포본에서 PyMuPDF를 완전히
  뺐습니다.
