# OMR Grader 4.5.0

상태: 빌드 후보. 빌드 번호 46.

학생이 학번을 잘못 칠한 답안지를 다시 칠하고 스캔하지 않고 프로그램에서 바로 고칠 수 있게 한
버전입니다. 판독 엔진과 채점 규칙은 바꾸지 않았습니다.
**자료 형식 변경: 1 → 2.** 4.5.0으로 연 자료 폴더는 4.4.x 이하에서 읽기 전용으로 열립니다.

## 바뀐 점

- **상세 결과 화면에 '학번 고치기'가 생겼습니다.** 학생을 고르고 누르면 답안지 왼쪽 위(손글씨 성명 ·
  학번과 칠한 학번 칸)가 함께 보여, 학생이 쓴 학번과 칠한 칸을 바로 비교할 수 있습니다.
  - **명단에서 찾기**로 이름을 고르면 학번이 채워집니다. 직접 8자리를 입력해도 됩니다.
  - 입력한 학번과 칠한 칸이 다른 자리는 그림에 주황색 테두리로 표시됩니다.
  - 명단에 없는 학번이면 저장 전에 한 번 묻고, 같은 시험의 다른 답안지와 학번이 겹치면 알려 준 뒤
    저장을 허용합니다(두 답안지 모두 '중복확인필요'로 표시).
- **확인할 학생이 눈에 띕니다.** 상세 결과 목록에서 읽지 못했거나 명단에 없는 학번은 주황색 행으로,
  요약에 '학번 확인 필요 n명'으로 보입니다. 고친 학번은 초록색 행에 '(수정)'이 붙습니다.
- **저장하면 결과가 모두 따라 바뀝니다.**
  - 채점결과 엑셀(채점 전이면 응답결과 엑셀)이 새 학번 · 이름으로 다시 만들어지고, 비고에
    '학번 수정(원래 …)'이 남습니다. 응답원본 탭에도 고친 학번이 들어갑니다.
  - 채점 이미지 파일 이름(`<순번>_<학번>_<이름>.jpg`)도 새 학번 · 이름을 따릅니다.
  - **합산 성적표**가 고친 학번으로 학생을 맞춰, 파트마다 따로 나뉘던 학생이 한 사람으로 합쳐집니다.
- **판독한 학번은 그대로 남습니다.** 수정은 별도 기록으로 남아 다시 채점해도 유지되고, '학번 고치기'의
  **원래대로**로 칠한 학번으로 되돌릴 수 있습니다. 백업 · 복구와 이전 버전 자료 가져오기에도 함께
  옮겨집니다.
- 도움말 '5. 학번 · 답 고치기'와 자주 묻는 질문에 사용법을 더했습니다.
- **앞으로의 안전장치:** 자료 폴더와 백업 파일이 형식 번호 하나를 함께 씁니다. 새 종류의 기록을 저장하면서
  번호를 올리지 않으면 테스트가 실패하도록 해, 예전 버전이 새 자료를 잘못 다루는 일을 빌드 전에 막습니다.

## 주의

- 자료 형식이 2로 바뀝니다. 4.5.0으로 자료 폴더를 한 번 열면, 그 폴더를 4.4.x 이하로 열 때 자료를
  보호하려고 읽기 전용으로 엽니다. 새 폴더에 설치하고 '이전 버전 자료 가져오기'로 옮기는 기존 업데이트
  방법을 쓰면 예전 폴더는 그대로입니다.
- **4.5.0에서 만든 백업(.omrbak)은 4.4.x 이하에서 복구되지 않습니다.** 백업 파일에도 같은 형식 번호(2)를
  적어, 학번 수정 기록을 모르는 예전 버전이 복구하지 못하게 했습니다. 4.5.0은 예전 백업(형식 1)을 그대로
  복구하고, 더 새 버전의 백업은 "더 새 버전 OMR Grader에서 만든 백업"이라고 알려 주고 복구하지 않습니다.
- 이번에 고칠 수 있는 것은 학번뿐입니다. 답은 지금처럼 응답 엑셀을 고쳐 다시 가져오는 방법으로
  고칩니다.

## 검증 결과

- 합성 자료로 채점 전 · 채점 후 고치기, 다시 채점 뒤 유지, 원래대로, 중복 표시와 해소, 잘못된 입력 거부,
  합산 성적표 합쳐짐, 백업 · 복구 뒤 유지를 확인하는 통합 테스트를 더했습니다.
- 고치기 창(명단 찾기, 다른 자리 표시, 그림 없는 답안지, 원래대로)과 상세 결과 표시, 저장 뒤 화면을 새
  판으로 다시 여는 흐름의 화면 테스트를 더했습니다.
- 실제 졸업고사(파트 2개, 각 10쪽)의 복사본에서, 학번을 잘못 칠한 파트2 답안지 1장을 고치자 합산
  성적표가 11행(같은 학생이 둘로 나뉨)에서 10행으로 합쳐졌습니다. 채점결과 엑셀의 이름 빈칸은 0,
  비고의 '학번 수정' 1건, 채점 이미지 10장 모두 고친 학번 · 이름이었습니다.
