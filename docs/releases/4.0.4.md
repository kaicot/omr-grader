# OMR Grader 4.0.4

상태: 배포 후보(빌드 번호 29). 검증 결과는 아래에 적습니다.

[4.0.3](4.0.3.md)의 시험 관리 화면과 휴지통 오류를 고친 버전입니다. 판독 엔진과 채점
규칙은 바꾸지 않았습니다.

## 고친 문제

- **휴지통이 늘 비어 있던 문제.** 휴지통 목록을 읽는 기능이 화면에 연결되어 있지 않아,
  삭제한 시험이 있어도 '휴지통 보기'에 아무것도 나오지 않았습니다(예전 버전부터 있던
  오류). 이제 삭제한 시험이 폴더 이름 · 상태 · 응시 인원으로 나오고, 복원과 영구 삭제가
  됩니다. 여러 시험을 골라 한꺼번에 복원하거나 지울 수 있습니다. '영구 삭제'와 '휴지통
  비우기'는 버튼을 눌러도 화면에서 처리되지 않던 오류도 함께 고쳤습니다. 휴지통 작업을
  하면 창이 닫히고 시험 관리 목록이 새로 고쳐집니다.
- **휴지통 폴더 이름.** 삭제하면 `_휴지통\세션\scan-977f…`처럼 내부 번호로 바뀌던 것을,
  원래 시험 폴더 이름 그대로 넣습니다.
- **시험 폴더 이름을 날짜 먼저로.** `26_1졸업고사p1_261007_165225` 대신
  `261007_165225_26_1졸업고사p1`입니다. 탐색기와 휴지통에서 날짜순으로 정렬되고 안의
  결과 Excel 이름과도 맞습니다. 응답 Excel로 시작한 시험도 같은 형식입니다(예전에는 내부
  번호였습니다).
- **삭제해도 목록에 남던 문제.** 삭제가 끝나자마자 목록을 다시 읽으려다 삭제 작업이 아직
  정리 중이라 거절되어, 새로고침 전까지 목록에 남고 상태 표시줄에 "작업 서비스가
  올바르지 않은 응답을 반환했습니다"가 잠깐 떴습니다(예전부터 있던 오류). 이제 작업이 완전히
  끝난 뒤 목록을 다시 읽고, 다른 작업 중에 들어온 새로고침도 끝난 뒤 실행합니다.
- **상세 보기에서 돌아오면 '관리' 칸이 찌그러지던 문제.** 열 너비를 버튼이 그려지기 전에
  재서 생긴 문제로 보고, '관리' 열을 버튼 크기에 맞춘 고정 너비로 바꿨습니다.
