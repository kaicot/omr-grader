# OMR Grader 2.1.2

상태: 로컬 배포 후보(빌드 번호 23) 문서화 단계. 최종 EXE, 전체 테스트, 최종 기술
게이트의 승인을 의미하지 않습니다.

2.1.1 위에서 실제 시험 채점 중 확인된 결함 세 가지를 고친 버전입니다. 포터블 경로,
배포 형식, receipt 형식 2와 검증 절차는 [2.1.1](2.1.1.md)과 같습니다.

## 고친 문제

- **채점 후 `DASHBOARD_SESSION_NOT_FOUND`로 결과가 사라지던 문제.** 평균이
  나누어떨어지지 않으면(예: 226÷3) 소수점 26자리로 저장되었고, 시험 목록은 12자리를
  넘는 숫자를 거부해 그 시험을 목록에서 빼 버렸습니다. 이제 평균은 정확한 값에서
  소수점 12자리로 반올림(half-up)해 저장합니다. 나누어떨어지는 평균(75.5, 80 등)은
  이전과 같은 문자열로 저장됩니다.
- **똑바로 스캔된 장을 180° 돌려 읽던 문제.** 프로필 표식만으로 방향을 고르면 답안
  표가 학번 영역보다 진한 양식에서 180° 쪽 점수가 더 높게 나왔습니다. 이제 첫 판독에서
  확실히 읽힌 답이 90% 미만이면 반대 방향으로 한 번 더 읽고, 그 방향에서 90% 이상
  확실히 읽힐 때만 방향을 바꿉니다. 답안 표가 거의 대칭이라 똑바른 장을 뒤집어 읽어도
  실제 스캔에서 최대 60%까지 '정상'으로 읽혔기 때문에, 그보다 약한 근거로는 방향을
  바꾸지 않습니다. 첫 판독이 확실한 장은 이전과 같이 한 번만 읽습니다.
- **채점 실패를 정답표 오류로 표시하던 문제.** 정답표가 이미 검증된 뒤 채점 같은 다른
  작업이 실패하면 "정답표 검증 오류를 수정하세요."를 띄우고 채점 버튼을 막았습니다.
  이제 검증 결과와 버튼은 유지하고 실제 오류만 표시합니다.

화면의 평균은 소수점 둘째 자리까지 표시합니다(예: 75.33점). 저장값은 12자리입니다.

## 데이터 호환

2.1.0과 2.1.1이 26자리 평균으로 저장한 시험은 열기만으로 파일을 수정하지 않으며,
읽을 때 12자리로 반올림해 목록과 상세 화면에 표시합니다. 이런 시험도 상세 화면 열기,
답 수정 저장, 재채점, 확정을 할 수 있으며, 새로 저장되는 결과는 12자리 평균을
씁니다. 저장된 점수와 다시 계산한 점수를 비교하는 검사는 비교 전에 저장된 평균만
12자리로 맞추며, 다른 항목은 이전과 같이 정확히 비교합니다.

## 남은 제한

- 인쇄 양식의 위치나 크기가 페이지마다 다른 스캔은 칸이 어긋날 수 있습니다. 정렬
  보정은 이번 범위가 아니므로 검수 화면에서 확인합니다.
- 작은 점처럼 옅게 표시한 답안은 기본 감도 5에서 '불확실'이 많을 수 있습니다. 감도를
  높이면 줄어들지만, 새로 읽힌 답은 검수 화면에서 확인합니다.

```powershell
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe -m ruff check src tools

& .\tools\build-portable-folder.ps1 -BuildNumber 23
& .\tools\verify-portable-folder.ps1 -ReleaseRoot <dir> -Smoke Both -StrictShutdown
```

OneDrive 같은 reparse 경로 아래에서는 빌드하지 않습니다. 출력 위치 지정, 산출물 구조와
환경 준비는 [2.1.1 릴리즈 문서](2.1.1.md)를 따릅니다.
