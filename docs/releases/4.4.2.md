# OMR Grader 4.4.2

상태: 배포됨. 빌드 번호 45, GitHub 릴리즈
[v4.4.2](https://github.com/kaicot/omr-grader/releases/tag/v4.4.2)(태그 커밋 `3fdfe3f`).

명단 엑셀을 더 너그럽게 읽도록 고친 버전입니다. 판독 엔진과 채점 규칙은 바꾸지 않았습니다.
**자료 형식 변경: 없음**(형식 1).

## 바뀐 점

- **명단의 연번 · 학번이 숫자로 저장돼 있어도 읽습니다.** Excel에 1, 2, 3이나 학번을 입력하면 숫자로
  저장되는데, 예전에는 이 칸을 글자로만 받아 "명단 파일을 읽지 못했습니다"(오류 코드
  `XLSX_CELL_TYPE`)가 났습니다. 연번은 비어 있어도 됩니다.
- 숫자로 저장된 학번은 적힌 그대로 씁니다. 숫자 칸에서는 앞자리 0이 사라지므로, 8자리가 아닌 학번은
  예전처럼 '학번 확인 필요'로 표시하고 0을 추측해 붙이지 않습니다.
- **명단 오류 문구가 문제 칸을 짚어 줍니다.** 예: "명단 5행 B칸(학번)을 읽지 못했습니다." 첫 줄 이름이
  다를 때, 수식이 있을 때, 칸이 더 있을 때도 각각 알맞은 안내가 나옵니다.

## 검증 결과

- 숫자 연번 · 숫자 학번 · 소수 · 앞자리 0이 빠진 학번 · 오류 칸 위치를 확인하는 테스트를 더했습니다.
- 실제 중간고사(40문항 양식, 15쪽)를 임시 복사본으로 처음부터 끝까지 돌렸습니다. 숫자 연번 명단을
  읽어 학번 15명이 모두 명단과 맞았고, 답 600칸 모두 정상 판독, 15명 모두 채점되었습니다.
- 전체 테스트: 1862개 모두 통과. ruff, mypy: 문제 없음.
- 포터블 폴더 검증(`-Smoke Both -StrictShutdown`): `VERIFIED_ZIP_STRICT_SMOKE_PASS`, 두 번 연속 통과.
  다른 위치로 옮긴 폴더의 실행 시험도 통과했습니다.
