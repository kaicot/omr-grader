# OMR Grader 4.3.0

상태: 후보. 빌드 번호 40(후보).

조용히 틀리게 읽을 수 있던 경우를 **노란 칸(확인 필요)**으로 돌린 판독 개선 버전입니다. 채점
결과가 4.2.4와 달라질 수 있습니다. 대신 프로그램이 확신하지 못하는 답은 점수에 넣지 않고 사람이
확인하게 합니다. **자료 형식 변경: 없음**(형식 1). 예전 버전에서 저장한 시험은 그대로 엽니다.

## 바뀐 점

- **두 개 칠했는데 하나가 훨씬 연할 때.** 같은 문항의 두 번째 표시가 첫 번째의 75%보다 연하면
  '두 개 칠함'(자동 오답)이 아니라 확인 필요로 둡니다. 수정테이프로 덮고 남은 자국이나 지운 자국
  때문에 억울하게 오답 처리되던 경우입니다. 똑같이 진하게 두 개 칠하면 예전처럼 '두 개 칠함'입니다.
- **그 답안지의 다른 답보다 유난히 연한 표시.** 같은 답안지에서 칠한 답의 보통 진하기의 절반보다
  연한 표시는 지운 자국일 수 있어 확인 필요로 둡니다. 실제 졸업고사 24쪽에서 가장 연하게 칠한 답도
  보통 진하기의 57%였으므로, 실제 답은 그대로 읽힙니다.
- **스캔에서 잘린 칸.** 스캔이 기울거나 밀려 칸이 이미지 밖으로 나가면, 예전에는 그 칸을 빈칸
  (무응답)으로 읽었습니다. 이제 확인 필요로 둡니다.
- **학번은 8칸 모두 칠해야 합니다.** 마지막 칸을 비워도 7자리 학번으로 통과하던 것을 확인 필요로
  바꿨습니다.
- **인식 감도는 1~7.** 7보다 높이면 연한 자국까지 답으로 읽어 확인 필요가 조용한 오답으로 바뀔
  뿐이어서 최대값을 7로 줄였습니다. 예전에 8~10으로 저장한 설정은 7로 열립니다.
- **한 번에 200장 넘게 넣으면 먼저 묻습니다.** 메모리가 부족해 느려지거나 멈출 수 있어, PDF를 나눠
  채점한 뒤 '합산 성적표'로 합치는 방법을 안내하고 계속할지 묻습니다.
- 도움말 '자주 묻는 질문'에 "노란 칸이 예전보다 많아졌어요"를 더했습니다.

## 검증 결과

**합성 판독 시험**(가짜 답안지로 만든 위험 상황, 인식 감도 5, 4.2.4 → 4.3.0, "숨은 오답"은 확인
필요 없이 틀리게 읽은 수):

| 상황 | 문항 | 숨은 오답 | 정상 판독 | 확인 필요 |
| --- | ---: | ---: | ---: | ---: |
| 일반 답안 | 300 | 0 → 0 | 300 → 300 | 0 → 0 |
| 진짜 답 옆에 남은 자국 | 99 | 53 → **0** | 10 → 10 | 36 → 89 |
| 수정테이프 자국 | 99 | 14 → **0** | 54 → 54 | 31 → 45 |
| 빈 문항에 남은 자국 | 99 | 52 → **6** | 14 → 14 | 33 → 79 |
| 가장자리가 잘린 스캔 | 270 | 66 → **0** | 204 → 0 | 0 → 270 |
| 연하게 칠한 진짜 답 | 99 | 4 → 4 | 64 → 33 | 31 → 62 |
| 똑같이 두 개 칠함 | 99 | 0 → 0 | 99 → 66 | 0 → 33 |
| 학번 끝자리 비움 | 12장 | 틀린 학번 통과 6 → **0** | | 6 → 12 |

- 남은 숨은 오답: 빈 문항의 진한 자국 6건(보통 진하기의 50~54%로, 실제로 연하게 칠한 답과 구분할 수
  없는 구간)과 지름 약 1 mm의 아주 작은 점 4건(빈칸으로 읽음).
- 연하게 칠한 진짜 답과 작은 점 두 개는 확인 필요로 더 많이 갑니다. 자국과 구분할 수 없어서 사람이
  확인하게 한 대가입니다.
- 인식 감도에 따른 차이가 거의 없어졌습니다(빈 문항 자국: 감도 3에서 6건, 10에서 7건. 4.2.4는
  46건 → 74건).
- 가짜 자국은 실제 자국을 흉내 낸 것이라, 숫자는 실제 오답률이 아니라 4.2.4와의 비교 기준입니다.

**실제 자료**
- 실제 졸업고사 24쪽(G1, 파트 교차 포함 4가지): 틀린 답 0, 확인 필요 0, 학번 불일치 0. 4.2.4와 같습니다.
- 흔들림 시험(G2, 회전 · 확대 · 10 mm 밀림 · 압축 · 밝기 · 뒤집힘 등 12가지 × 2파트): 모두 틀린 답 0,
  확인 필요 0. 4.2.4와 같습니다.
- 처음부터 끝까지 흐름(E2E): 두 파트 모두 점수가 정답과 일치합니다.
- 새 60문항 양식 시험 쪽(1쪽): 60문항 모두 정상 판독, 학번 정상.
- 규칙마다 따로 넣고 그때마다 위 측정을 반복했습니다. 기록은 비공개 기준 폴더의 결과 기록표에
  남겼습니다.

(빌드 · 엄격 검증 결과는 빌드 후 기록)

## 알려진 한계

- 보통 진하기의 50~54% 사이의 진한 자국은 실제 연한 답과 구분할 수 없어 답으로 읽힐 수 있습니다.
- 지름 약 1 mm보다 작은 점은 빈칸으로 읽힐 수 있습니다.
- 답을 거의 칠하지 않은 답안지(칠한 답 10개 미만)는 '유난히 연한 표시' 판정을 하지 않습니다.
- [4.2.1의 알려진 한계](4.2.1.md#알려진-한계)는 그대로입니다.
