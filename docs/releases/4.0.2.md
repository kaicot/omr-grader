# OMR Grader 4.0.2

상태: 배포 후보(빌드 번호 27). 검증 결과는 아래에 적습니다.

[4.0.1](4.0.1.md)을 실제로 쓰면서 나온 요청을 반영한 버전입니다. 판독 엔진과 채점 규칙은
바꾸지 않았습니다. 포터블 경로, 배포 형식, receipt 형식 2와 검증 절차는 4.0.1과 같습니다.

## 바뀐 점

- **첫 화면 스크롤바.** 기본 창 크기에서 다섯 칸이 다 보이지 않아 오른쪽에 스크롤바가
  생겼습니다. 명단·스캔 끌어놓기 칸의 위아래 여백을 줄이고, "명단 연결됨: (경로)" 줄은
  2번 제목 옆의 "명단 연결됨"으로 옮겼습니다(경로는 아래 끌어놓기 칸과 마우스를 올렸을 때
  보입니다). 1195×883 화면에서 높이가 60px 남고, 그보다 63px 낮은 창에서도 스크롤바가
  생기지 않습니다.
- **채점결과 Excel 하나로.** 채점이 끝난 시험 폴더에는 `02_score_…_채점결과.xlsx` 하나만
  보입니다. 탭은 다음과 같습니다.
  1. 채점결과: 학번 · 이름 · 총점 · 석차 · Q1~Q100 · 비고. 이름 가나다순이고, 이름이 없는
     학생(명단 없이 채점)은 맨 아래에 학번순입니다. 석차 값은 그대로라 석차로 다시 정렬할
     수 있습니다.
  2. 응답결과: 읽은 답 그대로(번호 · 파일명 · 학번 · 이름 · Q1~Q100 · 비고). 이 탭 덕분에
     채점결과 Excel을 그대로 '응답 엑셀로 시작'으로 가져올 수 있습니다. 노란 칸(확인 필요)이
     남은 줄은 비고에 "확인 필요: …번"이 적혀 있어, 고치고 그 문구를 지우기 전에는 가져오지
     않습니다.
  3. 정답표: 채점에 쓴 정답과 배점
  4. 색 설명

  예전 '응답내역' 탭은 '응답결과' 탭과 겹쳐 없앴습니다. 확정본(`03_final_…`)도 같은
  구성입니다. 응답결과 Excel과 정답표 사본은 내부 기록에 그대로 남고 폴더에서만 보이지
  않습니다. 채점 전에는 지금처럼 `01_ocr_…_응답결과.xlsx`가 보입니다. 4.0.1 이전에 채점한
  시험은 다음에 채점할 때 이 구성으로 바뀝니다.
- **페이지 이미지 용량.** `01원본스캔`의 페이지 이미지(기울기·회전을 바로잡은 페이지)를
  압축 없는 컬러 PNG 대신 흑백 JPEG(품질 90)로 저장합니다. 채점 전 `01인식결과이미지`도
  JPEG이고, 내부 기록에 같은 이미지를 한 번 더 두던 사본은 저장하지 않습니다. 판독은
  압축하지 않은 페이지로 하므로 결과는 같습니다. 이 이미지는 채점 이미지와 상세 보기에만
  씁니다. 이미 저장된 시험의 PNG는 그대로 두고 새로 스캔하는 시험부터 적용합니다.

  | 실제 시험 한 파트(12장, 원본 PDF 7.6MB) | 4.0.1 | 4.0.2 |
  |---|---|---|
  | 페이지 이미지 | 43MB(장당 3.6MB) | 11.5MB(장당 0.96MB) |
  | 채점 전 인식결과 이미지 | 164MB(장당 13.7MB, 내부에 한 번 더) | 16.4MB(장당 1.4MB) |
  | 채점 전 시험 폴더 전체 | 447MB | 60MB |
  | 채점 후 시험 폴더 전체 | 61.5MB | 29.7MB |
