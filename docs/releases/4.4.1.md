# OMR Grader 4.4.1

상태: 배포됨. 빌드 번호 44, GitHub 릴리즈
[v4.4.1](https://github.com/kaicot/omr-grader/releases/tag/v4.4.1)(태그 커밋 `6c0cb09`).

4.4.0에서 놓친 경우를 고친 버전입니다. 100문항 답안지로 50문항 시험처럼 **답안지보다 적은 문항을
출제한 시험**도 결과 엑셀과 정답표 요약이 실제 출제 문항 수를 따릅니다. 판독 엔진과 채점 규칙은
바꾸지 않았습니다. **자료 형식 변경: 없음**(형식 1).

## 바뀐 점

- **채점결과 엑셀은 정답표의 마지막 출제 문항까지만 보여 줍니다.** 100문항 답안지에 50문항 정답표로
  채점하면 채점결과 · 결과OX · 응답원본 · 판독 근거 · 정답표 탭이 모두 Q1~Q50에서 끝납니다. 4.4.0은
  답안지에 인쇄된 문항 수만 봤기 때문에 이런 시험은 Q100까지 빈칸이 남았습니다.
- 정답표 범위 밖(예: 51번 이후)에 학생이 칠한 표시는 점수와 관계없으므로 엑셀에서 빠집니다. 그
  표시가 애매해도 비고에 '확인 필요'로 적지 않습니다. 원본 스캔과 채점 이미지에는 그대로 남습니다.
- **정답/채점 화면의 미출제 문항 수는 정답표의 마지막 출제 문항 안에서 비워 둔 문항만 셉니다.**
  100문항 답안지에 50문항 정답표면 "출제 50 · 미출제 0"입니다(4.4.0은 미출제 50으로 보였습니다).
- 채점 전의 응답결과 엑셀은 아직 정답표를 모르므로 지금처럼 답안지에 인쇄된 문항까지 보여 줍니다.
- 이미 채점한 시험은 같은 정답표로 다시 채점하면 엑셀이 새 모양으로 바뀝니다. 다시 채점하면 이전
  결과가 새 결과로 바뀌므로, 필요하면 먼저 시험 관리의 '백업하기'를 하세요.

## 검증 결과

- 합성 자료: 100문항 답안지 + 50문항 정답표를 실제로 스캔 → 채점해 엑셀이 Q50에서 끝나는지,
  정답표 밖의 애매한 표시가 비고에 남지 않는지, 정답표 중간에 비운 문항은 미출제로 세는지 확인하는
  테스트를 더했습니다.
- 실제 졸업고사 자료(파트 2개, 24쪽):
  - 100문항 답안지에 실제 정답표의 1~50번만 넣어 채점하면 채점결과 56열 · 응답원본 55열로 Q50에서
    끝나고, 채점 전 응답결과 엑셀은 105열 그대로입니다.
  - 100문항 정답표(106열)와 50문항 변형(56열)은 4.4.0과 같습니다.
  - 세 경우 모두 점수가 기준 기록과 일치했습니다.
- 전체 테스트: 1859개 모두 통과. ruff, mypy: 문제 없음.
