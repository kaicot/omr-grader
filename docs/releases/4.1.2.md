# OMR Grader 4.1.2

상태: 배포됨. 빌드 번호 34, GitHub 릴리즈
[v4.1.2](https://github.com/kaicot/omr-grader/releases/tag/v4.1.2)(태그 커밋 `2ef8d9a`).

휴지통이 화면에서 작동하지 않던 오류를 고치고, 도움말을 새로 만든 버전입니다. 판독 엔진과
채점 규칙은 바꾸지 않았습니다.

## 고친 문제

- **휴지통의 복원 · 영구 삭제 · 휴지통 비우기가 작동하지 않던 문제.** 휴지통 창이 목록을
  읽는 작업이 끝나기 직전(아직 작업 중인 상태)에 열려, 세 버튼이 처음부터 꺼진 채로
  만들어졌고 요청도 거절되었습니다. 오류 메시지도 없이 아무 일도 일어나지 않았습니다.
  4.0.4에서 고쳤다고 적었지만 그때는 저장소 단계만 확인했고 화면 경로는 확인하지 않았습니다.
  이제 목록 작업이 완전히 끝난 뒤 창을 엽니다. 실제 버튼을 눌러 처리까지 가는지 확인하는
  테스트를 더했고, 실제 프로그램 구성으로 삭제 → 복원 → 다시 삭제 → 휴지통 비우기를 끝까지
  확인했습니다.
- 꺼진 '영구 삭제' · '휴지통 비우기' · '삭제' 버튼이 빨간 글씨 그대로라 눌리는 것처럼
  보이던 것을 회색으로 바꿨습니다.
- 시험 관리에서 작업을 마친 뒤 상태 표시줄이 "처리 중"에 머물던 것을 고쳤습니다. 이제
  "휴지통에서 시험을 복원했습니다." 같은 결과를 보여 줍니다.
- '휴지통 비우기'를 눌러도 "선택한 시험을 영구 삭제하시겠습니까?"라고 묻던 문구를 "휴지통의
  시험 n개를 모두 영구 삭제합니다"로 고쳤습니다. 복원과 영구 삭제도 개수를 적습니다.

## 바뀐 점

- **휴지통 창.** 기본 크기로 작게 열리던 창을 780×460으로 키웠습니다. 목록을 시험 폴더 ·
  상태 · 응시 인원 · 채점일시 표로 바꾸고, 삭제한 시험 수를 위에 적습니다. 복원은 왼쪽, 되돌릴
  수 없는 영구 삭제 · 휴지통 비우기는 오른쪽에 떨어뜨리고 닫기 버튼을 더했습니다.
- **도움말 새로 만듦.** 왼쪽 목차와 오른쪽 설명, 위쪽 검색 칸으로 바꿨습니다. 처음 시작하기 ·
  OMR 스캔 · 정답/채점 · 결과 엑셀 보는 법 · 시험 관리 · 답 고치기 · 합산 성적표 · 백업과
  휴지통 · 환경 설정 · 자주 묻는 질문 · 프로그램 정보를 표, 단계 그림, 색 견본, 팁 · 주의 상자로
  정리했습니다. 지금 보고 있는 화면의 장이 먼저 열리고, **F1** 키로도 열립니다. 어두운
  테마에서도 색이 맞춰집니다.
