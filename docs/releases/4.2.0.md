# OMR Grader 4.2.0

상태: 배포됨. 빌드 번호 35, GitHub 릴리즈
[v4.2.0](https://github.com/kaicot/omr-grader/releases/tag/v4.2.0)(태그 커밋 `617410e`).

새 버전 안내와 이전 버전 자료 가져오기를 더한 버전입니다. 판독 엔진과 채점 규칙은 바꾸지
않았습니다. **자료 형식 변경: 없음**(형식 1. `Data\FORMAT.json` 표시만 새로 씀).

## 새 기능

- **새 버전 안내.** 프로그램을 켤 때 하루 한 번 GitHub에 최신 릴리즈 번호를 묻습니다. 새 버전이
  있으면 왼쪽 메뉴 아래에 "새 버전 v…이 있습니다"와 **다운로드 페이지** · **건너뛰기** 버튼이
  뜹니다. 오프라인이거나 5초 안에 답이 없으면 아무것도 표시하지 않습니다.
  - 보내는 정보는 프로그램 버전(`OMR-Grader/4.2.0`)뿐이며 시험 · 학생 자료는 보내지 않습니다.
  - 자동으로 내려받거나 설치하지 않습니다. 다운로드 페이지는 이 프로젝트의 릴리즈 페이지만
    엽니다.
  - 환경 설정 **4. 업데이트와 자료 가져오기**에서 끄거나 **지금 확인**으로 직접 확인합니다.
    설정은 프로그램 폴더의 `update.json`에 저장됩니다.
- **이전 버전 자료 가져오기.** 새 버전을 새 폴더에 풀고 처음 실행하면 묻습니다(나중에 환경
  설정에서도 가능). 예전 프로그램 폴더를 고르면 시험 · 답안지 양식 · 환경 설정을 복사합니다.
  - 시험마다 '백업하기 → 백업 복구하기'와 같은 길로 옮겨 검증하고, 원래 폴더 이름 그대로
    만듭니다. 예전 휴지통의 시험은 새 휴지통으로 옮겨 복원할 수 있게 둡니다.
  - 예전 폴더는 바꾸지 않습니다. 문제가 있으면 예전 버전을 그대로 쓰면 됩니다.
  - 이미 가져온 시험은 건너뛰므로 다시 실행해도 안전합니다.
- **자료 형식 표시.** 처음 실행할 때 `Data\FORMAT.json`에 자료 형식 번호(1)를 적습니다. 앞으로
  형식이 바뀐 새 버전의 자료를 예전 버전(4.2.0 이상)으로 열면 읽기 전용으로 열어 자료를
  보호합니다.

## 고친 문제

- **백업 복구한 시험의 폴더 이름.** '백업 복구하기'로 되살린 시험이 `scan-…` 같은 내부 번호
  폴더로 만들어지던 것을, 원래의 `날짜_시각_시험명` 이름으로 만듭니다. 같은 이름이 있으면
  `_2`를 붙입니다.

## 검증 결과

- 실제 졸업고사 자료가 든 빌드 33 폴더의 **복사본**에서 가져오기: 활성 시험 1개(채점결과 엑셀,
  채점 이미지 12장)와 휴지통 시험 1개가 원래 이름으로 옮겨지고, 휴지통 시험을 새 버전에서
  복원함. 답안지 양식 1개와 설정도 옮겨짐. 실제 프로그램 구성(run)으로 첫 실행 안내 → 폴더
  선택 → 가져오기 → 휴지통 복원까지 확인.
- 합성 자료 테스트로 예전 폴더의 파일이 하나도 바뀌지 않음을 확인.
- GitHub 실제 응답으로 최신 릴리즈(4.1.2) 확인.
- 전체 테스트: 실패는 이 PC에서 예전부터 실패하던 환경 문제 3건뿐입니다.
- ruff, mypy: 문제 없음.
- 포터블 폴더 검증(`-Smoke Both -StrictShutdown`): `VERIFIED_ZIP_STRICT_SMOKE_PASS`. 다른
  위치로 옮긴 폴더의 실행 시험도 통과했습니다.
- 배포 ZIP `OMR-Grader-fixed35-20261008.zip`의 SHA-256:
  `4675b7efd09bd0d8ffc9088266606de3a88416e1f6d184d545a07f4ea2ac9410`

## 알려진 한계

- 가져오기는 백업과 같이 시험마다 최신 채점 결과만 옮깁니다. 그 전에 채점했던 내부 기록은
  옮기지 않습니다.
