# OMR Grader 4.0.1

상태: 배포 후보(빌드 번호 26). 검증 결과는 아래에 적습니다.

[4.0.0](4.0.0.md)의 판독 엔진과 채점 규칙은 그대로 두고, 실제로 써 보며 불편했던 화면,
속도, 결과 Excel을 고친 버전입니다. 포터블 경로, 배포 형식, receipt 형식 2와 검증 절차는
4.0.0과 같습니다.

## 바뀐 점

- **스캔 화면 순서.** 위에서부터 차례로 채우면 되도록 바꿨습니다.
  1. 시험명
  2. 응시 학생 명단(선택)
  3. 스캔 파일/폴더
  4. 인식 프로필(스캔을 고르면 자동 지정)
  5. 고급 인식 설정

  인식 프로필은 스캔을 고르면 정해지므로 스캔 아래로 옮겼습니다. 목록과 '다른 프로필
  불러오기'는 그대로 있고, 큰 프로필 끌어놓기 칸 대신 4번 칸 아무 곳에나 프로필 파일을
  끌어놓으면 됩니다. 'OMR 인식 실행'과 '인식 취소'는 맨 아래로 옮겼고, 실행할 수 없을
  때는 무엇이 빠졌는지 버튼 옆에 알려 줍니다. 4번 칸은 스캔을 고르기 전 안내, 양식 확인
  중, 찾음(✓), 주의(⚠), 실패(✗)를 구분해 보여 주고, 실패하면 목록과 불러오기 버튼을
  강조합니다.
- **진행 표시.** 멈춘 것처럼 보이던 구간을 없앴습니다.

  | 작업 | 표시 |
  |---|---|
  | 양식 자동 인식 | 4번 칸에 "답안지 양식을 확인하는 중 (3 / 6쪽)", 그다음 "양식을 정리하는 중" |
  | OMR 인식 | 스캔 파일 준비(n / N쪽) → 답안지 판독(n / N쪽, 남은 시간) → 인식 결과 저장 |
  | 채점 | 시험 기록 읽기 → 점수 계산(n / N명) → 채점 이미지와 결과 Excel 저장 |

  셀 수 없는 구간은 막대가 계속 움직이고, 경과 시간은 1초마다 바뀝니다. 남은 시간은 실제로
  센 진행이 있을 때만 보여 줍니다. 4.0.0까지는 OMR 인식 중 처리한 쪽 수가 화면에 전달되지
  않았습니다. 스캔 파일을 준비하는 동안 '인식 취소'를 누르면 오류가 나던 것도 고쳐, 이제
  그 단계에서도 취소됩니다.
- **속도.**
  - 채점: 저장된 시험 기록을 읽을 때 기록 하나마다 자료형 정보를 다시 해석하던 것을 한
    번만 하도록 바꿨습니다. 같은 결과를 읽습니다.
  - 양식 자동 인식: 앞 12장 대신 앞 6장으로 양식을 정합니다. 해상도는 낮추지
    않았습니다. 동그라미를 찾는 기준이 판독 해상도에 맞춰져 있어, 낮추면 실제 시험으로
    기준부터 다시 검증해야 하기 때문입니다.
- **결과 Excel 색 표시.** 예전 엔진처럼 열자마자 문제가 보이게 했습니다. 값과 열 구성은
  바꾸지 않았으므로 응답결과 Excel은 '응답 엑셀로 시작'으로 그대로 다시 가져옵니다.
  - 채점결과(`02_score_…`)와 확정본(`03_final_…`): 틀린 답·무응답·중복 표기(틀린 것으로
    채점)는 분홍 바탕에 빨간 글씨, 확인 필요(인식이 애매해 검토 전까지 채점하지 않음)는
    노란 바탕입니다. 확인 필요가 있는 학생은 총점이 비고 그 칸도 노랗게 칠하며, 비고에
    "확인 필요: 3~5, 17번"처럼 문항 번호를 적습니다. 맞힌 답과 정답표에 없는 문항은 색을
    칠하지 않습니다. 색의 뜻은 '색 설명' 시트에 있습니다.
  - 응답결과(`01_ocr_…`): 확인 필요 칸을 노랗게 칠하고, 비고에 "확인 필요: …번"과 학번을
    읽지 못한 경우 "학번 확인 필요"를 적습니다.
  - 두 Excel 모두 머리글 행을 굵게 하고, 첫 행과 학번·이름 등 앞 네 열을 고정해 100번까지
    옆으로 넘겨도 누구의 줄인지 보입니다.
- **상세 결과는 보기 전용.** 채점 이미지의 동그라미를 눌러 답을 바꾸던 기능과 '수정사항
  저장' 버튼을 뺐습니다. v4 채점 이미지에서는 눌러도 아무 표시가 없어, 바뀐 줄 모르는
  '저장되지 않은 수정사항'만 쌓였습니다. 확대·축소, 이동, 학생 목록과 점수는 그대로입니다.
  답을 고쳐야 하면 응답결과 Excel의 사본을 고친 뒤 '응답 엑셀로 시작'으로 가져와 다시
  채점합니다. 검토 편집 화면은 다음 버전에서 다시 만듭니다.
- **화면 이동과 종료가 막히던 오류.** '저장되지 않은 수정사항' 창에서 어떤 버튼을 눌러도
  취소로 처리되어 다른 화면으로 가거나 프로그램을 끌 수 없었습니다. 이 창이 쓰는 PySide6
  6.11은 버튼 값을 정수로 돌려주는데 코드가 이를 같은 객체인지로 비교했기 때문입니다. 누른
  버튼을 직접 비교하도록 고치고, 버튼 이름을 '저장', '저장하지 않고 나가기', '취소'로
  바꿨습니다. 4.0.1에서는 상세 화면에 수정 기능이 없으므로 이 창이 뜨지 않습니다.
- **상세 결과에서 이미지가 사라지던 오류.** 학생 A, B를 차례로 본 뒤 A로 돌아가면 A의 채점
  이미지가 빈 화면으로 남았습니다. 보이는 학생의 이미지만 메모리에 두면서 이미 불러온
  것으로 기록해 다시 불러오지 않았기 때문입니다. 이제 돌아가면 다시 불러옵니다.
- **결과 폴더 정리.**
  - 시험 폴더의 `generations`는 채점할 때마다 그 시점 결과를 확정해 두는 내부 기록입니다.
    저장 도중 꺼져도 기록이 깨지지 않게 하고, 백업·복구 때 파일이 바뀌지 않았는지 검사하는
    데 씁니다. 이 폴더를 숨김으로 둡니다. 시험 폴더 바로 아래의 결과 Excel은 이 기록의
    파일과 같은 파일(하드 링크)이라 공간을 두 번 쓰지 않습니다. 이미 있는 시험은 다음에
    채점하거나 복구할 때 숨겨집니다.
  - 재채점할 때마다 시험 폴더에 빈 `.staging` 폴더가 하나씩 남던 것을 저장이 끝나면
    지웁니다.
  - 내부 JSON 파일(`CURRENT.json` 등)은 숨기지 않습니다. 저장할 때마다 새 파일로 바뀌어
    숨김 표시가 유지되지 않기 때문입니다.
- 도움말을 지금 순서(양식 자동 인식, 보기 전용 상세 결과, Excel 색 표시)에 맞게 고쳤습니다.

## 알려진 한계

- [4.0.0의 알려진 한계](4.0.0.md#알려진-한계)는 그대로입니다.
- 상세 결과에서 답을 고칠 수 없습니다. 위의 응답결과 Excel 경로를 쓰세요.
- 양식 자동 인식은 앞 6장만 봅니다. 앞쪽 6장 가운데 다른 양식이 섞여 있으면 4번 칸에
  "확인한 6쪽 가운데 n쪽은 양식이 달라 보입니다"가 뜹니다. 확인한 장이 모두 다른 양식이면
  그 양식으로 인식될 수 있으니, 처음 보는 양식 확인 창의 요약과 미리보기를 확인하세요.
