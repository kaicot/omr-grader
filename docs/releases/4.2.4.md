# OMR Grader 4.2.4

상태: 배포됨. 빌드 번호 39, GitHub 릴리즈
[v4.2.4](https://github.com/kaicot/omr-grader/releases/tag/v4.2.4)(태그 커밋 `f4ccd85`).

엑셀 파일을 읽다 멈추던 문제를 고친 버전입니다. 판독 엔진과 채점 규칙은 바꾸지 않았습니다.
**자료 형식 변경: 없음**(형식 1).

## 고친 문제

- **명단을 넣으면 인식이 멈추던 문제.** 다른 프로그램이나 변환 도구로 만든 엑셀은 파일 안에
  "표 크기 정보"가 빠져 있기도 합니다(Excel로 만든 파일에는 항상 들어 있습니다). 이런 명단을 넣으면
  'OMR 인식 실행'이 `WORKER_TYPEERROR`로 멈췄습니다. 이제 크기 정보가 없으면 실제 칸을 세어 읽습니다.
  같은 문제가 있던 **정답표**와 **응답 엑셀로 시작**도 함께 고쳤습니다.
- **명단을 읽지 못할 때의 안내.** 막연한 "작업을 완료하지 못했습니다" 대신, 첫 줄이 '연번 · 학번 ·
  이름'인지 확인하고 Excel로 다시 저장해 보라고 알려 줍니다. 명단 없이도 인식할 수 있다는 점도
  알려 줍니다. 도움말 '자주 묻는 질문'에도 넣었습니다.
- **오류 위치 기록.** 예상하지 못한 오류가 나면 프로그램 코드의 어느 파일 몇째 줄에서 났는지를
  로그에 남깁니다. 학생 이름이나 학번이 섞일 수 있는 오류 문장은 지금처럼 남기지 않습니다.
