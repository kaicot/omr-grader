# OMR Grader 4.2.1

상태: 후보. 빌드 번호 36(후보).

새 기능 없이 4.2.0까지 쌓인 문제를 점검해 고친 버전입니다. 판독 엔진과 채점 규칙은 바꾸지
않았습니다. **자료 형식 변경: 없음**(형식 1). 4.2.0 자료를 그대로 엽니다.

## 시험 폴더와 저장

- **결과 Excel을 열어 둔 채 다시 채점.** 예전에는 시험 폴더의 원본 스캔 · 채점 이미지 폴더가
  사라지고 예전 결과 Excel만 남은 채로 고쳐지지 않았습니다(자료는 숨김 기록에 남아 있었음).
  이제 Excel이 열려 있으면 폴더는 그대로 두고 "닫은 뒤 새로고침을 누르세요"라고 알립니다.
  Excel을 닫고 시험 관리에서 **새로고침**을 누르면 폴더가 새 결과로 바뀝니다. 채점 이미지
  같은 폴더 안의 다른 파일을 열어 두었다면 그동안 폴더 일부가 비어 보일 수 있지만, 자료는
  보존되고 닫은 뒤 새로고침하면 같은 방법으로 되돌아옵니다.
- **고쳐 저장한 결과 Excel.** Excel에서 고쳐 저장한 결과 파일은 다시 채점할 때 지우지 않고
  `…_사용자수정본.xlsx`로 남깁니다.
- **시험 하나 때문에 목록이 통째로 비던 문제.** 손상된 시험, 탐색기로 만든 시험 폴더 복사본,
  빈 `새 폴더`, 휴지통에 들어간 다른 폴더 때문에 시험 관리나 휴지통 목록 전체가 비던 것을
  고쳤습니다. 문제 있는 폴더만 빠지고, 그 폴더 이름과 이유가 표시됩니다. 복사본은 원래 폴더만
  목록에 나오며 프로그램은 어느 쪽도 지우지 않습니다.
- **탐색기에서 이름을 바꾼 시험 폴더.** 목록에서 사라지던 것을, 바뀐 이름 그대로 쓰도록
  고쳤습니다. 휴지통에 넣고 복원해도 바뀐 이름을 유지합니다.
- **`Data\.locks`가 빠진 복사.** 폴더를 일부만 복사해 잠금 폴더가 없으면 시험이 모두 숨고
  삭제 · 복원이 실패하던 것을, 목록을 열 때 다시 만들도록 고쳤습니다.
- **읽기 전용 실행.** 쓰기 권한이 없는 폴더에서 시험 목록이 비던 것을, 아무것도 쓰지 않고
  목록을 보여 주도록 고쳤습니다. 새 형식 자료를 읽기 전용으로 열 때도 내부 목록 파일과 잠금
  파일을 쓰지 않습니다.
- **영구 삭제.** 읽기 전용 표시가 붙은 파일이 있으면 삭제가 반쯤 남던 것과, 삭제할 때마다
  내부 정리 경고가 생기던 것을 고쳤습니다. 중간에 멈춘 삭제는 다음에 목록을 열 때 마저
  정리합니다.
- **4.0.0~4.0.2에서 만든 시험.** 가져오거나 복원하면 시험 폴더에 결과 Excel이 보이지 않던
  것을 고쳤습니다(예전 이름 그대로 보입니다).

## 화면

- **채점 중단 버튼을 숨겼습니다.** 눌러도 채점이 멈추지 않는 버튼이었습니다. 스캔 취소는
  그대로 작동합니다.
- **다른 작업 중에 누른 버튼.** 시험 관리의 채점하기가 작업 중에도 실행되어 다른 시험의
  화면과 섞일 수 있던 것을 막았습니다. 작업 중에는 파일을 고르기 전에 "다른 작업이 끝난 뒤
  다시 시도하세요"라고 알립니다. 작업이 막 끝난 순간에 누른 버튼이 거부되던 것도 고쳤습니다.
- **성공 메시지를 덮던 빨간 안내.** 삭제 · 복원 · 가져오기 뒤에 "대시보드 인덱스를
  재구축했습니다"가 빨갛게 덮어쓰던 것을 없앴습니다.
- **환경 설정의 '저장하고 있습니다' · '가져오는 중…'** 문구가 남던 것을 고쳤습니다.
- **응답 엑셀로 시작**한 뒤 "OMR 인식 완료"라고 나오던 것을 "응답 엑셀을 불러왔습니다"로
  고쳤습니다.
- **휴지통에서 여러 시험을 한 번에** 복원 · 삭제할 때 하나가 실패해도 나머지를 계속하고,
  몇 개가 되었는지 알려 주며 목록을 다시 읽습니다.
- **처음 실행할 때 묻던 '이전 버전 자료 가져오기'**를 없애고, 시험 관리가 비어 있을 때 같은
  이름의 버튼을 보여 줍니다. 환경 설정 '4. 업데이트와 자료 가져오기'에도 그대로 있습니다.
- 백업 파일이 이미 있을 때, 시험 삭제가 실패할 때, 같은 시험이 이미 있을 때(휴지통 포함)
  알 수 없는 문구 대신 이유를 한국어로 알립니다.

## 엑셀과 가져오기

- **합격 기준을 `60%`로 적으면** 0.6%로 읽어 거의 모두 합격으로 나오던 것을 고쳤습니다.
  `60` 또는 `60%`로 적으면 됩니다. 서식 없이 `0.6`처럼 적으면 다시 적도록 알립니다.
- 합산 성적표 파트 탭의 채점 시각이 UTC(+00:00)로 나오던 것을 한국 시각으로 고쳤습니다.
- 정답표의 모든 열에서 수식을 거부합니다.
- **이전 버전 자료 가져오기**
  - 예전 폴더에 `_휴지통` · `.locks` 같은 폴더를 만들던 것을 고쳐, 이제 예전 폴더는 읽기만
    합니다. 읽기 전용 폴더에서도 가져옵니다.
  - 읽을 수 없는 시험이 있으면 그 시험만 이유와 함께 건너뛰고 나머지를 가져옵니다.
  - 다시 실행할 때 답안지 양식이 `_2`, `_3`으로 늘어나던 것을 고쳤습니다.
  - 환경 설정을 저장하지 못했으면 가져왔다고 하지 않고 그렇게 알립니다.
- **새 버전 확인.** 공용 와이파이 로그인 화면처럼 이상한 응답에도 조용히 넘어갑니다.

## 도움말

- 한 번에 넣는 스캔은 200장 이하를 권장합니다(한 장에 약 15 MB의 메모리). 50명 정도의 반은
  문제없습니다. 더 많으면 PDF를 나눠 채점하고 '합산 성적표'로 합칩니다.
- 인식 감도는 기본 5를 권장합니다. 높이면 '확인 필요'로 걸러질 흐린 표시가 답으로 읽혀
  조용히 틀릴 수 있습니다.
- 결과 Excel을 열어 둔 채 다시 채점했을 때, `_사용자수정본`, 폴더 복사본 · 이름 바꾸기에 대한
  질문을 더했습니다.

## 검증 결과

- 전체 테스트: 실패는 이 PC의 화면 배치 탓에 4.2.0에서도 실패하던 2건뿐입니다. 예전부터
  환경 탓에 실패하던 테스트 3건은 테스트를 고쳐 통과합니다.
- 새 저장 테스트 14건: Excel이나 채점 이미지를 열어 둔 채 다시 채점, 고쳐 저장한 Excel,
  정리 중 멈춘 뒤 폴더에서 빠진 파일, `.locks` 삭제,
  복사본 · 빈 폴더 · 손상된 시험, 휴지통의 낯선 폴더, 이름 바꾼 폴더, 읽기 전용 저장소,
  실제 쓰기 거부 권한(ACL), 읽기 전용 파일의 영구 삭제, 4.0.2 이전 이름의 Excel.
- 실제 졸업고사 자료가 든 빌드 33 폴더의 **복사본**: 활성 1개 · 휴지통 1개가 경고 없이
  보이고, 목록을 열어도 파일이 하나도 바뀌지 않음.
- 실제 자료 판독 기준(24쪽): 틀린 답 0, 학번 불일치 0. 처음부터 끝까지 흐름: 점수 일치.
- ruff(규칙 확대: import 정렬, 흔한 버그 패턴, 시간대, 단순화)는 프로그램 코드(`src`, `tools`)에서
  문제 없음. 테스트 코드는 이번 규칙 확대 대상에서 뺐습니다. mypy: 문제 없음.
- 독립 코드 검토: 막는 문제 없음. 지적된 두 가지(폴더 파일이 빠졌을 때 잘못된 안내, 채점 이미지를
  열어 둔 채 다시 채점)는 고치고 테스트를 더했습니다.

## 알려진 한계

- 시험 폴더의 `02채점결과이미지`나 `01원본스캔` 파일을 지우거나 고치면 그 시험은 목록에서
  빠집니다(이제 다른 시험은 그대로 보입니다). 백업에서 복구하세요.
- 시험 폴더의 `02채점결과이미지` 같은 결과 폴더에 직접 넣은 다른 파일은 다시 채점하거나 폴더를
  새 결과로 바꿀 때 지워질 수 있습니다. 결과 폴더에는 파일을 넣지 마세요.
- 4.0.3 이전 버전에서 그대로 덮어 쓴 폴더에 남은 예전 이름의 채점 Excel(`02_score_…`)은
  사용자 파일과 구분할 수 없어 지우지 않고 둡니다.
- 가져오기를 다시 실행하면 예전 폴더의 환경 설정으로 다시 덮어씁니다.
- 판독 엔진의 한계(지운 자국, 잘린 열, 7자리 학번 등)는 다음 기능 버전에서 다룹니다.
- [4.2.0의 알려진 한계](4.2.0.md#알려진-한계)는 그대로입니다.
