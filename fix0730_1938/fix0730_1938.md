[Task] OMR Grader 프론트엔드 UI 버그 수정, 테마 스타일링 및 치명적 스레드 블로킹(응답없음) 오류 해결

다음 피드백을 바탕으로 [정답/채점] 화면의 버튼 상태와 [시험관리] 화면의 테마, 레이아웃 버그, 그리고 앱 강제 종료를 유발하는 로직 오류를 수정해 주세요.

### 1. [정답/채점] 화면: 상태별 버튼 텍스트 변경
- **현상**: '채점 실행' 버튼이 비활성화(Disabled) 상태일 때, 사용자가 언제 버튼이 활성화되는지 인지하기 어려움.
- **수정 요청**: 
  - 버튼이 비활성화(`disabled=true`) 상태일 때, 버튼의 텍스트를 `채점 실행 (채점이 완료되면 채점 결과보기가 활성화 됩니다)`로 변경해주세요.
  - 활성화(`disabled=false`) 상태일 때는 기존처럼 `채점 실행`으로 렌더링되도록 조건부 렌더링(Conditional Rendering)을 적용해주세요.

### 2. [시험관리] 화면: 테마 및 레이아웃 CSS 버그 수정
- **현상 1 (체크박스 투명화)**: 밝은 테마(Light Theme) 적용 시 '선택' 컬럼의 체크박스가 보이지 않고, 어두운 테마(Dark Theme)일 때만 보임.
- **수정 요청 1**: 라이트 테마 환경에서 체크박스의 테두리(border)와 배경색(background-color) CSS 변수가 하얀색(투명)으로 묻히지 않도록, 라이트 테마용 체크박스 CSS 컬러 값을 명도 대비가 뚜렷한 색상(예: 어두운 회색/검정 테두리)으로 수정해주세요.
- **현상 2 (버튼 텍스트 짤림)**: 관리 탭의 '상세보기' 및 '삭제' 액션 버튼 안의 글자가 버튼 영역을 벗어나거나 잘려서(Clipping) 보임.
- **수정 요청 2**: 해당 버튼들의 `font-size`를 줄이고, `padding` 값을 최적화하며, `white-space: nowrap` 등을 적용하여 텍스트가 버튼 UI 안에 온전히 들어가도록 CSS를 조정해주세요.

### 3. [시험관리] 화면: 상태 업데이트(새로고침) 누락 수정
- **현상**: '삭제' 버튼 클릭 후 나타나는 확인 모달(Confirm Alert)에서 '확인'을 눌러 삭제를 진행해도, 화면 목록에서 해당 항목이 즉시 사라지지 않음(수동 새로고침 필요).
- **수정 요청**: 삭제 로직(API 또는 DB 삭제)이 성공적으로 완료된 후(Callback 또는 await 이후), 프론트엔드의 시험 목록 상태 배열(List State)에서 해당 아이템을 제거하거나 전체 리스트 데이터를 다시 Fetching하여 화면이 즉각적으로 리렌더링(Re-render)되도록 상태 관리 로직을 수정해주세요.

### 4. [시험관리] 화면: 메인 스레드 멈춤(응답없음) 크리티컬 버그 수정
- **현상**: '통합 성적표 생성' 버튼을 누른 후 (파일 저장 다이얼로그 등이 떴을 때) 저장하지 않고 창을 닫거나 취소(Cancel)하면, 프로그램 전체가 '응답 없음(Freeze)' 상태에 빠짐.
- **수정 요청**: 
  - 파일 저장 다이얼로그(File Save Dialog) 호출 시 사용자가 취소(Cancel) 버튼을 누르거나 창을 닫았을 때 반환되는 결과값(DialogResult.Cancel 등)에 대한 예외 처리(Exception Handling / 조건문 분기)가 누락되어 무한 루프나 데드락이 발생한 것으로 보입니다.
  - 해당 버튼의 이벤트 핸들러(Event Handler) 내부에 Try-Catch 문을 적용하고, 취소(Cancel) 시 함수를 안전하게 `return` 하여 UI 메인 스레드가 블로킹되지 않고 정상 복귀되도록 로직을 수정해주세요.
